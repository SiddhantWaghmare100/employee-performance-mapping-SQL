# Employee Performance Mapping using SQL

## Project Overview

This project focuses on Employee Performance Mapping for a Data Science startup using SQL and MySQL Workbench. The objective was to analyze employee performance, salary distribution, reporting hierarchy, and departmental insights through database management and SQL queries.

## Tools & Technologies

* SQL
* MySQL Workbench
* Relational Database Management System (RDBMS)

## Dataset Used

The project contains three datasets:

* emp_record_table
* proj_table
* data_science_team

## Key SQL Concepts Used

* DDL Commands
* DML Commands
* Aggregate Functions
* Joins
* Subqueries
* Views
* Stored Procedures
* Stored Functions
* Window Functions
* Indexing
* Query Optimization

## Project Features

* Employee performance analysis
* Department-wise employee rating comparison
* Salary analysis by role and geography
* Reporting hierarchy identification
* Employee ranking based on experience
* Bonus calculation
* Query optimization using indexes

## Files Included

* Employee_Project.sql

* ER Diagram
* Query Output Screenshots

## Conclusion

This project demonstrates practical implementation of SQL for employee analytics and database management using real-world business scenarios.
